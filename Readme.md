# Agentic AI for Developers and Architects
## 8-Day Hands-on Training Program

This intensive 8-day training program provides a practical introduction to Agentic AI and modern AI frameworks including LangChain, LangGraph, AutoGen, Semantic Kernel, Azure AI Foundry, Foundry IQ, MCP, and Microsoft Agent Framework.
